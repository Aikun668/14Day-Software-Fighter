本目录是本地矢量占位，不热链参考站，也不接随机头像服务。冻结图里的插画和头像不是可直接切出的透明素材。视觉验收状态：**资产未齐**。

| 文件 | 用途 | 来源与授权 |
| --- | --- | --- |
| `logo.svg` | 登录页与侧栏品牌标 | 本仓自绘。图形语义沿用 `BrandMark` 的刻度（右臂三道刻度），颜色与槽位按 00 品牌紫 `#8146FF`、冻结图「标在字左」校准。不是 Medix 商标文字，也不复制第三方标识文件。 |
| `doctor-assistant.svg` | 侧栏底部与登录页左下装饰 | 本仓自绘扁平插画（医生、植物、笔记本电脑），透明底、无文字、无截图白边。构图对照冻结图，精细度低于冻结图里的立体插画，属于占位。 |
| `avatar-neutral.svg` | 无真实头像时的人物占位；顶栏账号也用它 | 本仓自绘中性剪影，没有五官、没有照片。不把这张图当成任何真实患者或账号的脸。 |

## 头像规则

- `PatientAvatar` 只有在传入真实 `src` 时才表示本人照片。
- `demoSrc` 仅当调用方显式传入 `demo` 时启用。本目录没有按演示 fixture 预绑的人脸映射，避免给真实患者随机分配一张脸。
- 生产环境无照片时一律落到 `avatar-neutral.svg`。
