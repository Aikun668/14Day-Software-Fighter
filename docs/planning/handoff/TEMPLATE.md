# 交接文件模板

> 文件名：`<任务编号>-<日期>.md`，例如 `S0-2026-10-19.md`、`SA-A1-2026-10-20.md`。
> 存放：`D:\My_Grand_Projects2026\14Day-Software-Fighter\docs\planning\handoff\`（主仓库绝对路径）。
> 规则依据：[00-编排规则.md](../00-编排规则.md) §2.10。

---

```markdown
# 交接：<任务编号> <任务名>

| 项 | 值 |
|---|---|
| 会话编号 | S0 / SA / SB / SC / SD / SE |
| 任务编号 | 例如 A-1（可多个，如 A-1～A-2） |
| 状态 | 完成 / 进行中 / 阻塞 / 100k中断 （四选一，依赖门只看这一项） |
| 日期 | YYYY-MM-DD |
| 分支 / worktree | 例如 feat/ui-a，`D:\...\wt-a` |
| 上下文用量 | 约 XXk（若能判断） |

## 1. 做了什么
- 一句话一条，按任务编号列出。

## 2. 改动文件
| 文件 | 新增 / 修改 | 说明 |
|---|---|---|

## 3. 测试与验收（原始数字，不美化）
| 项 | 命令 | 结果 |
|---|---|---|
| 新增测试 RED 证据 | | 失败输出摘要 |
| 新增测试 GREEN | | 通过数 |
| run_acceptance | | PASS / FAIL 数，对比 P0-3 基线 |
| 覆盖率（若涉及） | | 数字与目标 |
| 未跑的项 | | 写「未跑」并说明原因 |

## 4. 证据
- 截图或输出存放路径：`docs/evidence/ui-upgrade-2026-10-<任务编号>/`

## 5. 待合并文档条目（不在本会话改，交 SE）
- [ ] API_SPEC.md：…
- [ ] TASKS.md「本轮增补」：…
- [ ] 软件说明书.md §…：…
- [ ] docs/TESTING.md：…

## 6. 越界登记（若有需要改动但不在本会话所有权内的文件）
| 文件 | 原因 | 建议由谁处理 |
|---|---|---|

## 7. 锁
- 本会话占用过的资源：…
- 已在 `LOCK.md` 删除本会话的行：是 / 否

## 8. 阻塞与需用户决定的问题
- …

## 9. 下一个会话需要知道的事（背景）
- 关键路径、已踩过的坑、注意事项。
- 若状态为「100k中断」：写明停在哪一步、下一步第一条命令是什么。

## 10. 未提交改动
- `git status --short` 摘要；是否已 commit（仅在授权时）；commit hash。
```
