## P2-01 状态文字及选中标志过浅

- 03：今日用药面内“待登记”，约 x149–205、y179–198；“已登记”，约 x309–363、y240–259。
- 05：选中“完成”一行，约 x25–365、y565–610，包含文字与左侧圆形白勾。
- 03 杏色文字对近白底约 2.0:1，青绿文字约 2.4:1；05 青绿文字对浅青绿选中背景约 2.2:1。数值来自文字区域有效彩色像素中位数与背景采样，为栅格估算，不冒充运行页面的对比度测试。
- 修法：杏色文字加深至约 `#995712`，青绿文字加深至约 `#14776A`；保留原有活力配色。05 勾选圆底也加深至可读青绿，白勾保留；否则文字修好了，关键选中标记仍过浅。
- 普通正文目标至少 4.5:1，必要控件图形至少 3:1。禁用的“上一步”不要求改成启用态颜色。
