# 规则、优先级与冲突裁决

## 优先级
用户最新明确要求 > 本包最新文字条款 > 本包指定冻结图的构图 > 旧设计文档。
现有 API 与身份权限约束持续有效；视觉图片不构成改变权限或数据含义的依据。

## 硬性格式
R01 白色侧栏/顶栏、浅中性灰主画布；轻盈、略有活力。禁止旧 Clinic Comfort 大标题、大圆角、厚阴影。
R02 页面不嵌套卡片。表格行、任务行、关注项用留白和细线分隔；表单输入边框、状态格、图标按钮不算嵌套内容卡。
R03 字号通过 token + rem，根字号保持浏览器默认 16px，不给 html 设 font-size。正文 0.9375rem，标签至少 0.8125rem。
R04 品牌紫仅用于品牌、主动作、导航和选中；图表另用蓝趋势、青绿登记、杏色缺口。不同患者的同一指标不随机染色。
R05 普通操作使用灰色描边/图标；状态色只表达含义，不能加装饰圆点。
R06 状态不能仅凭颜色辨认；文字、图标名、tooltip/键盘说明需可用。

## 内容要求
R07 删除重复标题、系统正常、教学句、副标题、常态编号列、姓名下编号、用户列下面的 admin 元数据。删除显示不是删除字段或记录。
R08 patient_code 保留在内部、搜索、必填建档表单、同名消歧的搜索结果/详情中；普通列表不显示。
R09 写实头像用于已授权真实头像或明确演示数据；无真实头像用中性人物图标，不拿虚构脸冒充真实患者。演示图片可用固定的合成人像映射。
R10 登记覆盖不等于依从性；未发现登记不等于漏服。N=0 显示无到期时点/—；统计失败显示不可用，不能显示 0% 或正常。
R11 编号、状态、版本、任务 ID 等业务字段按契约保留；分页、筛选、处理、评估和补登入口不能因效果图简化而丢失。
R12 固定日期/人物/数据只用于显式演示 fixture。业务界面读取当前接口，不复制图中 9、10、0% 或示例日期。
R13 管理员不继承临床权限。工作台医护内容不能出现在管理员页面。
R14 头像、插画、字体均本地可用；不访问随机头像服务，不热链参考站资源。插画不是必需功能，资产未完成时报告差异。

## 提交要求
R15 01–03 实际页面至少在 1440×900、1280×800、390×844 验收；200% 缩放键盘可操作。
R16 build/lint 与浏览器验收分别给证据；不可用效果图替代实际截图。
R17 UI 变更登记到 docs/planning/UI-OPTIMIZATION-LOG.md；冻结文件与原用户改动不覆盖。
R18 未处理缺陷和资产差异必须明示；未经用户确认不能宣称最终视觉验收通过。

## 工程补充（非用户截图原始要求）
E01 小屏适配、键盘焦点、同名消歧、失败重试、异步竞态保护属于必要实现细节。
E02 统一尺寸是从生成图归一到 1440×900 的工程值，不是 js.design 源文件量测。
E03 不新增测试框架仅测静态 CSS；新增/改动的数据转换或提交修复必须有有意义的行为验证。
