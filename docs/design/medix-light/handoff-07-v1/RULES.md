# 07补充规则

|ID|类别|规则|
|---|---|---|
|R01|硬性格式|只采用已确认06浅色外壳、蓝趋势、青绿登记、杏色未登记；品牌/选中紫色，不回到旧紫色仪表盘。|
|R02|硬性格式|独立白内容面，无内容卡嵌套；正文token+rem，html默认字号；长内容滚动，不缩成小字。|
|R03|内容|姓名只一处，前有写实演示头像；无患者编号/装饰色点/常驻解释/重复M、N小字。|
|R04|内容|07单独出图、出规格、出验收；仍共用/stats页签，不增加伪路由。|
|R05|内容|保留每日覆盖、未登记时点、来源、随访、重复登记；解释通过信息入口可读，不靠删除功能实现减法。|
|R06|内容|M为有登记的不同时点，来源为事件数；重复事件不增加M；N0不是0%，未发现登记不等于漏服。|
|R07|内容|图中12/14与85.7%等为演示；生产从真实接口读取。头像不能冒充真实患者。|
|R08|提交|保存项目内图像、完整提示词、独立自检、哈希；用户视觉确认与代理自检分开。|
|R09|提交|更新整体报告/目录/压缩包为v2，v1冻结原件不改，不修改前后端代码。|

优先级：用户最新要求 > 本包07条款 > 整体v2跨页规则 > 06通用数据契约 > 图中示意像素 > 历史07截图。原旧截图只用于核对功能，不提取旧视觉。

补充工程约定：真实来源横条按事件数计算宽度、图表坐标按数据绘制，不逐像素复制造图误差；所有操作必须有实际行为或禁用说明，不能为贴图生成不可用的假控件。
