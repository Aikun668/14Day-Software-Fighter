## 如何复核冻结

在仓库根执行：

```powershell
python docs/design/medix-light/handoff-05060809-v1/verify.py
```

如需核对本轮阅读基线，添加 --check-source。默认验证当前包、引用源及依赖；基线检查在代码实施开始后预期可能出现变化。脚本只读，不改文件。

validation.json 保存冻结前内容核验结果；FREEZE.json包含它及全部交付文件的哈希。冻结后再次运行脚本检查完整清单与Windows只读属性。只读属性可人为解除，SHA256用于检测更改，不能称不可篡改存储。
