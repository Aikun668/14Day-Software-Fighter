## 1. 软件概述

### 1.1 软件定位

本软件是一款面向呼吸慢病吸入治疗教育的**双客户端辅助管理软件**。医护人员通过电脑浏览器访问 Web 管理端，患者通过可安装的 Android 应用学习具体装置型号的操作方法、执行步骤自检和用药自报登记；两个客户端共用同一套后端服务与数据库。

### 1.2 主要用途

- 按**具体装置型号**提供经审核的吸入操作指导；
- 记录患者自述的操作自检与医护现场观察结果；
- 支持固定与按需两类用药计划的配置与用药自报登记；
- 通过**记录覆盖率**辅助医护人员识别登记缺失情况，形成待核查事项与随访闭环；
- 基于已审核的装置资料提供型号限定的操作问答。

### 1.3 软件特点

| 特点 | 说明 |
|---|---|
| 双端分离 | 医护端为桌面浏览器 Web 应用，患者端为可安装的 Android 应用，界面与交互各自适配 |
| 统一后端 | 两端共用同一套 REST 接口与同一个 PostgreSQL 数据库，数据实时一致 |
| 型号级内容 | 操作指导按具体装置型号与版本管理，型号之间不共用步骤 |
| 内容审核留痕 | 指导与知识内容须经审核方可发布，记录审核人与审核时间 |
| 记录可追溯 | 用药登记可撤销但不物理删除，保留撤销人、时间、原因与审计记录 |
| 统计口径明确 | 仅呈现"基于登记记录的覆盖率"，不表述为真实用药依从性 |

### 1.4 重要声明

本软件 V1.0 为**演示原型**，使用模拟数据，用于功能演示与教学辅助。软件**不具备**真实吸入装置的连接能力、动作识别能力或吸气量测量能力，**不能替代专业诊疗**。

## 4. 用户角色与权限

| 角色 | 主要能力 | 权限边界 |
|---|---|---|
| 患者 | 查看本人档案与计划、学习指导、操作自检、用药登记、本人记录与问答 | 仅能访问本人数据，不能编辑处方计划或临床评估 |
| 医护 | 管理所负责患者、配置用药计划、提交现场观察、查看统计、创建随访 | 仅能访问分配给自己的患者 |
| 管理员 | 管理账号与患者归属、维护装置目录与指导内容、发布知识、查看审计 | 管理功能不自动获得患者临床数据访问权 |

**权限校验原则**：所有权限判断均在服务端执行，前端菜单隐藏不作为权限依据。访问越权资源时统一返回"资源不可访问"，避免泄露资源是否存在。

## 5. 功能说明与操作步骤

### 5.1 通用：登录与账号安全

**操作步骤**：

1. 打开客户端（医护端为浏览器网址，患者端为手机应用图标）；
2. 输入账号与密码，点击"登录"；
3. 登录成功后按角色进入对应工作区。

**安全机制**：

- 密码采用哈希方式存储，不以明文保存；
- 登录后签发带唯一标识的访问令牌，服务端保存会话记录；
- 用户点击"退出"时，服务端将该会话标记为已撤销，原令牌立即失效；
- 患者端访问令牌仅保存在应用运行内存中，**关闭应用或系统结束进程后需重新登录**；
- 首次登录若被要求修改密码，改密前仅可使用身份查询、改密与退出功能。

### 5.2 医护端（Web）

#### 5.2.1 工作台

**功能**：集中查看负责患者数量、待核查任务与近期随访。

**操作步骤**：

1. 登录后默认进入"工作台"；
2. 顶部三张概览卡片分别显示负责患者数、待核查任务数与近期随访数；
3. 在"待核查任务"列表中点击某条任务，右侧显示该任务详情；
4. 点击"记录随访"跳转随访中心；点击"查看患者详情"跳转患者管理。

#### 5.2.2 患者管理

**功能**：查询、建立与编辑患者档案，绑定患者登录账号，提交现场观察评估。

**操作步骤**：

1. 在左侧导航选择"患者管理"；
2. 使用搜索框按患者编号或姓名检索；
3. 点击"新建患者"，填写患者编号、姓名或别名、诊断标签与备注后保存；
4. 患者编号重复时系统会提示并阻止保存；
5. 在患者行点击"现场评估"，选择装置型号与指导版本，填写评估结论后提交，生成一条来源为"医护观察"的训练记录。

#### 5.2.3 用药计划编辑

**功能**：为患者配置固定计划或按需计划，并查看历史版本。

**操作步骤**：

1. 在左侧导航选择"用药计划编辑"；
2. 在顶部下拉框选择目标患者；
3. 填写装置型号、药物名称、计划类型（固定/按需）、生效起止日期；
4. 固定计划需填写每日时点，每行一个时间（如 `08:00`、`20:00`）；
5. 点击"创建计划"提交；
6. 下方"历史版本"表格列出该患者全部计划版本及其生效区间。

**说明**：调整已生效计划时系统创建新版本并关闭旧版本生效期，历史登记与统计结果不受影响；按需计划不生成固定时点。

#### 5.2.4 统计与核查

**功能**：按患者与日期区间查看应记录时点数、有效登记时点数、记录覆盖率、来源分布与缺失时点。

**操作步骤**：

1. 在左侧导航选择"统计与核查"；
2. 选择患者，设置统计开始与结束日期；
3. 点击"查询"；
4. 页面自上而下显示：覆盖率与分子分母 → 来源分布 → 缺失时点列表。

**页面标注**：页面明确提示"基于登记记录的覆盖率，不等于实际服药依从性"；当分母为零时显示"暂无固定计划"而非 0%。

#### 5.2.5 随访中心

**功能**：处理待核查任务、填写随访记录、安排复训提醒。

**操作步骤**：

1. 在左侧导航选择"随访中心"；
2. "待处理任务"区显示当前待核查任务，点击"处理此任务"自动带入患者与任务；
3. 在"记录随访"表单填写随访日期、反馈与疑问、宣教措施、后续计划；
4. 如需处理该任务，勾选"关闭关联任务"；如需患者复训，勾选"安排复训提醒"；
5. 点击"保存随访"提交，随访记录、任务状态与患者提醒在同一事务中完成。

### 5.3 患者端（Android App）

#### 5.3.1 今日首页

**功能**：展示本人档案摘要、当前装置、近 7 天记录覆盖率、待办提醒与功能入口。

**操作步骤**：

1. 打开应用并登录；
2. 顶部显示本人姓名与患者编号、绑定装置情况；
3. 概览卡片显示近 7 天记录覆盖率与"已登记 / 应记录"数量；
4. "待办提醒"区显示需要本人完成的事项；
5. 通过"型号指导""操作自检""AI 助手""用药记录"入口进入相应功能。

#### 5.3.2 型号指导

**功能**：查看本人当前装置型号的已发布操作指导。

**操作步骤**：

1. 在底部导航选择"指导"，或从首页点击"型号指导"；
2. 页面显示装置指导标题与版本号；
3. 按顺序查看各步骤说明与注意事项；
4. 点击"开始自检"进入操作自检，点击"AI 助手"进入问答。

**说明**：仅显示已发布的正式指导版本，未完成审核的内容不可见。

#### 5.3.3 操作自检

**功能**：按步骤逐项自述完成情况并提交，查看本人历史自检记录。

**操作步骤**：

1. 进入"操作自检"；
2. 对每个步骤选择"完成""有困难"或"未完成"；
3. 点击"提交自检（患者自述）"提交；
4. 点击右上角"历史记录"查看本人过往自检记录（含来源与各项结果）。

**说明**：提交结果记录为"患者自述"，不代表装置检测通过。

#### 5.3.4 用药记录

**功能**：查看今日固定计划时点、登记用药、查看历史登记。

**操作步骤**：

1. 在底部导航选择"记录"；
2. "今日固定时点"区按时间列出各时点及其登记状态；
3. 对未登记的时点点击"登记"完成登记；
4. "历史记录"区按时间倒序列出既往登记及其来源。

**说明**：同一时点重复登记时系统会保留记录并提示重复；网络不可用时不会显示登记成功。

#### 5.3.5 AI 指导助手

**功能**：就本人当前装置型号提出操作相关问题，获取基于已审核资料的回答与出处。

**操作步骤**：

1. 进入"AI 助手"；
2. 输入装置操作相关问题（请勿输入姓名、电话等身份信息）；
3. 点击"提问"；
4. 查看回答及其下方列出的资料出处（资料名称、版本、片段位置）。

**回答状态说明**：

| 状态 | 含义 | 页面表现 |
|---|---|---|
| 已回答 | 找到可靠资料并作答 | 显示回答与资料出处 |
| 资料不足 | 没有足够依据 | 提示资料不足，建议咨询医护人员 |
| 超出范围 | 涉及剂量调整、诊断或急症 | 不作具体医疗建议，引导联系医护或及时就医 |
| 服务不可用 | 外部模型服务异常 | 提示稍后重试，不影响其他功能 |

### 5.4 管理员功能

**功能**：装置型号维护、操作指导审核发布、账号管理、审计日志查询。

**操作步骤**：

1. 使用管理员账号登录 Web 端；
2. 左侧导航选择"内容与账号管理"；
3. 在"装置型号"页签可新增与查看装置型号；
4. 在"指导版本"页签新建指导草稿（填写型号、版本、标题与操作步骤），
   草稿需先点击"审核通过"，再点击"发布"；已发布版本不可修改，如需更正须新建版本；
5. 在"账号"页签新建医护或管理员账号（可指定初始密码或由系统生成一次性临时密码）、
   停用或启用账号；账号停用后其原有会话立即失效；
6. 在"审计日志"页签按时间查看关键操作记录。

## 6. 核心业务规则与计算口径

### 6.1 记录覆盖率

| 指标 | 定义 |
|---|---|
| 应记录时点 N | 统计区间内已到期、有效固定计划生成并生效的时点数 |
| 有效已登记时点 M | 上述时点中，至少存在一条有效登记记录的不同时点数 |
| 记录覆盖率 | M ÷ N × 100%，保留一位小数；N 为 0 时显示"暂无固定计划" |

**边界规则**：

- 未来时点不计入分母；
- 按需用药登记不计入固定计划分母；
- 同一时点多次登记，分子只计一次；
- 已撤销的登记不计入统计；
- 计划版本变更不影响变更前时段的统计结果。

### 6.2 来源分布

来源分布按**有效登记事件条数**统计（可按时间点重复登记而多于有效时点数），分为"患者自述"与"医护观察"两类。

### 6.3 待核查任务

当某患者连续 3 个已到期的固定计划时点均无有效登记时，系统生成一条待核查任务供医护人员处理。同一患者同类型未关闭任务只保留一条；任务关闭后，同一批历史缺失不会重复生成任务，仅在出现新的符合条件缺失时才生成新任务。

### 6.4 计划版本

同一用药逻辑计划的多个版本生效区间不能重叠；版本变更时关闭旧版本的生效期，并将旧版本中未发生且未登记的未来时点置为已取消，不参与统计。

## 7. 数据安全与隐私保护

| 方面 | 措施 |
|---|---|
| 密码存储 | 采用哈希算法存储，不保存明文 |
| 会话管理 | 服务端保存会话记录，支持主动撤销与到期失效 |
| 权限校验 | 每次请求在服务端校验身份、角色与数据归属 |
| 数据隔离 | 医护人员仅能访问所负责患者，患者仅能访问本人数据 |
| 数据可追溯 | 登记可撤销但不删除，计划与内容变更保留版本与审计记录 |
| 审计内容 | 记录操作者、动作、资源与时间，不记录密码、令牌与问答原文 |
| 演示数据 | 全部为虚构模拟数据，不含真实身份信息、联系方式或病历 |
| 外部服务 | 问答请求不携带患者身份与诊疗信息 |
