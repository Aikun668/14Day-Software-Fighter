# 本轮实施与验收规则

用户已授权调整 00 公共框架、01 登录、02 工作台、03 患者管理，并要求独立子 Agent 验收，不达标退回。本轮是实现校准，不是重新选择风格。

## 硬性格式

1. 对照 approved-batch-01 的 01、02、03 冻结图。目标原图 1586×992，按宽等比归一到1440；实拍视口1440×900、DPR1。
2. 浅灰画布、白色外壳和单层白表；无框里框。紫色用于品牌/选中/主动作，常规行操作灰色。
3. 字号使用 token + rem；html 不设 font-size。字体必须检查实际浏览器呈现。
4. 姓名旁用写实演示头像；演示身份固定映射。真实患者有头像时使用真实来源，无头像时用中性图标。

## 内容要求

5. 后续确认文字高于生成图：删除编号列、姓名下编号、小字解释、重复筛选提示；不因追图恢复。
6. 登记状态采用青绿/杏色。N=0写“无到期时点”，登记覆盖不得改称服药依从性。
7. 保留搜索、服务端筛选/分页、新建患者、现场评估、补登与处理任务入口。用患者id和task.id定位，不能按姓名去重。
8. 默认队列展示7条，剩余可展开；接口有更多任务时保留全部任务入口。不得靠丢数据或裁切表格完成一屏。

## 交付要求

9. 修改真实前端代码，更新用户指定的 medix-light-full-ui/index.html 和01–03实拍。
10. 桌面、1280、390、长姓名/多任务/分页、错误与无头像状态均需验收。测试接口写入使用隔离fixture。
11. 独立子Agent对照实拍与目标，P0/P1/P2必须修完；记录退回与复验。不能冒称用户已签字。
12. build、lint、UI优化日志、对照证据齐全；冻结设计图不修改；其余12张画廊图片保留原始hash。

## 实测后的补充

- 原文字稿15px正文与冻结图观感有差距；这轮按用户“尽量1:1”校准为17px正文、22px标题、18px区块/导航，均经rem token适配。冻结文档原件不改，实施差异在本包明示。
- 浏览器字体以本地Noto Sans SC文件为准。常用字子集优先加载，罕用字自动使用完整文件。
- 验收主图是实际React页面加隔离演示API；真实8010后端另附截图，不把模拟提交当生产数据验收。
