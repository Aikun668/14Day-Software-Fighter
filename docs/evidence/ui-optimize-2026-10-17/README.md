## 为什么不用 oil-ui 自带的截图工具

本机 Chrome 启动器会在拉起浏览器后立即退出，DevTools 地址不写到 stderr，`scripts/shoot.mjs` 报“浏览器提前退出”。没有改动 skill 目录里的脚本，改用本目录的 Playwright 脚本取证，输出的图与 `shoot.mjs` 等价（整页 PNG）。
